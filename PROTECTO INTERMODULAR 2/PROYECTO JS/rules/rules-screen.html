RULES

Tienes tres oportunidades para completar todos los textos que puedas en un tiempo maximo. Una vez perdido las tres vidas el revólver girara con una bala en la recamara, si acciona el gatillo y se dispara MUERES si no sale la bala, se te devuelven las tres vidas y sigues hasta que se acabe el tiempo o vuelvas a equivocarte 3 veces.
